# CodeAlpha\_LanguageTranslationTool

web-based language translation tool using Flask and MyMemory Translation API.



\# Language Translation Tool



A web-based language translation application developed using Python and Flask.



\## Features

\- Translate text between multiple languages.

\- English to Tamil and Tamil to English translation.

\- Language selection and swap option.

\- Copy translated text.

\- Simple and user-friendly interface.

\- Error handling and input validation.



\## Technologies Used

\- Python

\- Flask

\- HTML

\- CSS

\- JavaScript

\- MyMemory Translation API
